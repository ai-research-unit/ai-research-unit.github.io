What the Paper Does

It gives the algebraic machinery for the classification, and the statistics that follow.

"We extend the classification of free fermionic heterotic–string models to vacua in which the SO(10) GUT symmetry is broken at the string level to the Pati–Salam subgroup."

"Using our classification method we recently presented the first example of a quasi–realistic heterotic–string vacuum that is free of massless exotic states."

"Within this method we are able to derive algebraic expressions for the Generalised GSO (GGSO) projections for all sectors that appear in the models. This facilitates the programming of the entire spectrum analysis in a computer code."

"The total number of vacua in the class of models that we classify is 251 ∼ 1015 . We perform a statistical sampling in this space of models and extract 1011 GGSO configurations with Pati–Salam gauge group."

"results demonstrate that one in every 106 vacua correspond to a three generation exophobic model with the required Higgs states, needed to induce spontaneous breaking to the Standard Model."

So the paper's two contributions are the algebra and the statistic: $2^{51}$ vacua, $10^{11}$ Pati–Salam, one in $10^6$ viable.

Summary in the Authors' Words

$2^{51}$: Where the Number Comes

From

In the free-fermionic construction the vacuum is specified by GGSO phases — a matrix of signs, one for each pair of boundary-condition vectors. With $N$ basis vectors there are $N(N-1)/2$ phases, and for the Pati–Salam class here $N=11$, giving $2^{55}$ before symmetries, reduced to $2^{51}$ after equivalences.

So the number is exact and computable, not an estimate. That is the strength of the method: the landscape is a finite set with a known size.

The corpus should record the exactness, because it is unusual in landscape discussions — most "landscape" counts are estimates; this one is a count.

The GGSO Algebra

"algebraic expressions for the Generalised GSO (GGSO) projections for all sectors that appear in the models." "facilitates the programming of the entire spectrum analysis in a computer code."

The GGSO projection is the generalised GSO projection that determines which states survive. In free-fermionic models it is a set of sign conditions on the vacuum's phase matrix.

Writing them algebraically means the spectrum for any vacuum is a formula in the phases, and the formula can be evaluated in code. So the whole $2^{51}$ landscape can be scanned.

The corpus should note the method's significance: it is the heterotic analogue of the D6-brane enumeration algorithm (2112.09632), and it achieves the same thing — turning model building into a search.

Two independent constructions, two enumeration algorithms, both in this batch. That is the methodology of modern string phenomenology, and the corpus should present it as such.

The First Exophobic Vacuum

"

the first example of a quasi–realistic heterotic–string vacuum that is free of massless exotic states."

**"Exophobic"

** — no fractionally charged states, no exotic colour triplets beyond the SM's. Why it is hard: the free-fermionic spectrum naturally contains fractionally charged states, because the $U(1)$ charges are rational and the surviving states can have $Q=\pm1/2,\pm1/3$ etc. Removing them requires the GGSO phases to project them all out, which is a strong condition. **And "quasi–realistic"

** means: three generations, the PS-breaking Higgs, and the SM Higgs doublets, with no exotics. So the model passes all five filters at once. The corpus should record the milestone: the first model in the batch's heterotic branch that could be the world's. And note that it was found by a search, not by construction — the classification produced it. That is a significant methodological point: a model that no one would have guessed was found by enumeration. Compare 2112.09630's unique unified D6-brane model, also found by search. Both branches' best models are search results.

The Statistic: One in

$10^6$"in every 106 vacua correspond to a three generation exophobic model with the required Higgs states, needed to induce spontaneous breaking to the Standard Model."

So the viable region is $\sim10^5$ vacua out of $10^{11}$ Pati–Salam configurations. That is sparse but not vanishingly so, and the corpus should note that it is large enough to contain many distinct models — which is the landscape problem again.

And it means the search is necessary: no amount of cleverness replaces scanning $10^{11}$ configurations.

One observation about the corpus's map

This paper is the heterotic branch's centrepiece, and it is worth comparing directly with its D6-brane counterpart.

The pattern is identical and the scales are ten orders apart. So the methodology of string phenomenology is uniform: enumerate, filter, and inspect the survivors.

And the corpus should present it that way, because it is more informative than presenting each cluster separately: the difference between heterotic and D6-brane model building is the size of the space and the technical filter, not the logic.

The one real difference is the exotics' fate: free fermions project them out at the string level; D6-branes must decouple them dynamically. That is a genuine advantage of the heterotic construction, and the corpus should state it.
