What the Paper Does

Massive gravity has two metrics: a physical one and a reference one. The Lagrangian has few parameters, but the reference metric can be chosen almost freely, so the theory describes many cosmologies. The authors ask what that freedom does in vacuum. A de Sitter or anti-de Sitter reference metric forces the vacuum solution onto the trivial branch, with proportional scale factors. An anti-de Sitter reference then forbids accelerated expansion for any matter obeying the energy conditions. The visible light cone is set by both metrics.

Summary in the Authors' Words

The freedom

"Massive gravity is a theory which has a tremendous amount of freedom to describe different cosmologies; but at the same time the various solutions one encounters must fulfill some rather nontrivial constraints."

Where it comes from

"Most of the freedom comes not from the Lagrangian, which contains only a small number of free parameters (typically 3 depending on counting conventions), but from the fact that one is in principle free to choose the reference metric almost arbitrarily — which effectively introduces a non-denumerable infinity of free parameters."

The question

"although changing the reference metric would lead to a different cosmological model, this does not mean that the dynamics of the universe can be entirely divorced from its matter content."

Vacuum can be structured

"even the set of vacuum solutions for massive gravity can have significant structure. In some cases the effect of the reference metric could be so strong that no conceivable material content would be able to drastically affect the cosmological evolution."

The trivial branch

"in those models of massive gravity with dS and adS reference metrics all the vacuum solutions behave as the solutions of the trivial branch, implying strictly proportional scale factors and cosmic times."

The no-go result

"The non-existence of homogenous and isotropic accelerating solutions for models with an adS reference metric is a general result which is valid for any model where both metrics can be written in a diagonal way in the same coordinate patch, having the same spatial curvature ($k=-1$), and assuming the absence of matter violating the energy conditions."

The causal consequence

"In view of the FLRW symmetries common to both metrics the light cones of both metrics have the same axes, those of the physical metric being inside or outside the light cones of the reference metric depending on the particular solution obtained when the material content is considered."

The disclaimer

"We are not suggesting that there are not massive cosmologies with FLRW reference metrics able to describe our Universe. In fact, we have proven that any universe can be described by massive gravity if one were to carefully choose an appropriate reference metric."
