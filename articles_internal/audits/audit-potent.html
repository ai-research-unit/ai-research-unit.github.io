What the file is for. It gives the potent family one glyph family with the kind in the subscript, releases $\Upsilon$ and $\nu$ for the wave-number pass, and lists the twelve checks that close a batch.

The reader's contract, in five lines.

  1. One glyph family, and the kind is in the subscript. $\tilde\Pi_{\mathrm{id}}$ and $\tilde\Pi_{\mathrm{nil}}$ are one letter in two kinds: $\Pi$ takes every capital layer, with the tilde in the quaternion and biquaternion layers and none in the tilde-free ones.

2. The Two Principles

The kind is in the subscript. An element of the potent family carries $\mathrm{id}$, $\mathrm{nil}$ or, in a later pass, $\mathrm{rt}$, once, as the first word of its subscript. Nothing else in the corpus carries one of those three words.

The layer is in the case. The case rule of the convention is untouched, because it is what tells the reader which algebra he is in. The tag is added beside it and never replaces it.

The division of labour is the point, and it is three-way. The accent says whether the layer is quaternionic: a tilde for the quaternion and biquaternion layers, nothing for the complex, split-complex and dual ones, an arrow for a pure element in any of them. The case says whether the algebra has a complex or a quaternionic factor: the capital $\Pi$ for the biquaternion and the tilde-free layers, the lower-case $\pi$ for the quaternion layers. The tag says the kind and nothing else. Before the pass one letter carried the layer and a second letter carried the kind, which is why each family needed a letter of its own and why $\tilde\Upsilon$ had to be unrelated to $\tilde\Pi$.

There is no third letter, and the tilde is the quaternion mark. The nilpotent is written with $\Pi$ in the capital and $\pi$ in the lower case, and nothing else; the old $\Upsilon$ is released. The accent follows the same rule as for every other special element and is not free: the tilde marks the quaternion and biquaternion layers and is written nowhere else, so the complex, split-complex and dual layers carry the plain capital, $\Pi_{\mathrm{nil}}$, beside the plain idempotent $\Pi_{\mathrm{id}}$ and the sign pair $\Pi_{\mathrm{id},\pm}$. A tilde on $\Pi_{\mathrm{nil}}$ in a tilde-free article is a false tag of exactly the kind this pass exists to remove, and no pattern check catches it, because the glyph is well formed.

The arrow is the third accent and it replaces the tilde. A pure nilpotent is $\vec\Pi_{\mathrm{nil}}$ or $\vec\pi_{\mathrm{nil}}$ and never carries both; the arrow is not a layer mark and says nothing about the algebra.

One consequence the sub-agent must enforce. The arrow-over-tilde rule of algebra-and-element-conventions says that a pure element carries the arrow and drops the tilde. Under the tag the arrow falls on the nilpotent and never on the idempotent: $\vec\Pi_{\mathrm{id}}$ and $\vec\pi_{\mathrm{id}}$ do not exist, and a file that writes one is wrong. This replaces the old sentence "an idempotent has no arrowed form at all", which was true only while the two kinds had different letters.

6. The Subscript Grammar

Four slots, in a fixed order: sector, kind, sign, index. The separators are commas. No sector label is written on a potent glyph anywhere in the corpus today, so the kind is in practice the first slot; the sector is named first so that the rule agrees with physics-units-and-common-elements-conventions.md §The Observables, the States and the Quantum Objects, which puts the sector before the role.

This is not a new grammar. index-and-notation-conventions already says the label comes first and an index already in the field follows it after a comma, $T_{\mathrm{em},\mu\nu}$ and $\tilde S_{\Psi,\mathrm{tot},\eta}$. The kind is a label of that kind, and the tag changes nothing about the rule.

Four rules, and the fourth is what the four contrasts above are for.

A bare word in upright roman is merged inside the kind's own group. $\tilde\Pi_{\mathrm{sym}}$ becomes $\tilde\Pi_{\mathrm{id,sym}}$, one \mathrm{} group with one comma. It does not become $\tilde\Pi_{\mathrm{id},\mathrm{sym}}$.

A label that is itself a macro or a nested group stays in its own slot after the comma. $\tilde\Pi_{\mathrm i}$ is the initial projection, and the roman i is an object name, so it becomes $\tilde\Pi_{\mathrm{id},\mathrm i}$ and not $\tilde\Pi_{\mathrm{id,i}}$; the same holds for $\tilde\Pi_{\mathrm x}$ and $\tilde\Pi_{\mathrm z}$. A nested content is copied verbatim, $\tilde\Pi_{s_{\mathrm{tot}}}\mapsto\tilde\Pi_{\mathrm{id},s_{\mathrm{tot}}}$.

A numeric or sign label is not merged, because the comma has to be read: $\tilde\Pi_{\mathrm{id},1}$ and not $\tilde\Pi_{\mathrm{id,1}}$.

The superscript is not touched. $\tilde\nu^{2}=0$ becomes $\tilde\pi_{\mathrm{nil}}^{2}=0$; the tag goes in the subscript and the power stays where it was. The same for $^{*}$, $^{\natural}$ and $^{\star k}$.

Already-tagged sites are skipped. If the first word of a \mathrm{} subscript is already id or nil the glyph is left alone, so the pass is idempotent and can be run twice.

8. The Conventions, File by File

The conventions are rewritten by hand and first, before any article. They are the definition, and an article edited before them would disagree with its own definition for the length of the batch. Eighteen convention files exist, nine in physics and nine in mathematical, and thirteen of them carry a glyph of the nine families. The other five are named at the end of this section, with the reason they are not opened.

General instructions for every convention file

  1. State the tag where the kind is defined, not in an appendix. Each special-element file gains one short subsection, §The Potent Tag, before or inside §The Idempotent Convention, and the two sections then use it.
  2. Rewrite the case-rule tables. Their Symbol column takes the tagged glyph; their Role column keeps its wording and loses the sentence that distinguishes the kind by a letter. A row that said the biquaternion layer writes $\tilde\Upsilon$ now says the same letter, the kind in the tag.
  3. Rewrite the coordinate displays of §The Coordinates, since they are the definition the articles copy.
  4. Rewrite the summary tables at the end of each file, Summary of Notation and the prose Summary. A file whose summary is stale fails the check.
  5. Do not change the algebra, the numbers, the references, or the wording of a theorem. The only words that change are those that name a glyph or distinguish two kinds by a letter.
  6. Keep the register of the file. These files are written in short declarative sentences; a rewritten paragraph keeps that register. No new emphasis, no new bold beyond the existing use for a definition.
  7. A row that says "where no tilde is written" carries the tag. The tag replaces the tilde distinction; it does not sit beside it. The pre-pass tables of the tilde-free layers read $\Pi$ and $\Upsilon$, and they are now $\Pi_{\mathrm{id}}$ and $\Pi_{\mathrm{nil}}$, with $\Pi_{\mathrm{id},\pm}$ for the pair of idempotents. The nilpotent row keeps the words where no tilde is written, because in those layers no tilde is written: only the letter changes. A table left in the pre-pass form is not a harmless survivor: it is the instruction the articles follow, so a file whose tables and prose still say $\Pi$ will grow new $\Pi$ long after the pass. This was the defect the review found in physics/special-element-conventions.md, whose three rows contradicted the mathematics file that had already been migrated. Check every table row, every case-rule sentence and every "Summary of Notation" row for the untagged spelling before the file is called finished.

import re, pathlib

KIND  = {'Pi': 'id', 'pi': 'id', 'Upsilon': 'nil', 'nu': 'nil'}
GLYPH = {'Pi': 'Pi', 'pi': 'pi', 'Upsilon': 'Pi', 'nu': 'pi'}
# the family is six sites and not eight: \vec\Pi and \vec\pi are not sites
SITES = [('Pi', 'Pi', 'id', ('tilde',)), ('pi', 'pi', 'id', ('tilde',)),
         ('Upsilon', 'Pi', 'nil', ('tilde', 'vec')), ('nu', 'pi', 'nil', ('tilde', 'vec'))]

def read_sub(s, i):
    r"""s[i] == '_'. Return (content, end): balanced {...} or a single token."""
    j = i + 1
    if j < len(s) and s[j] == '{':
        depth, k = 0, j
        while k < len(s):
            if s[k] == '\\':
                k += 2
                continue
            if s[k] == '{':
                depth += 1
            elif s[k] == '}':
                depth -= 1
                if depth == 0:
                    return s[j + 1:k], k + 1
            k += 1
        raise ValueError('unbalanced subscript at %d' % i)
    m = re.match(r'\\?[A-Za-z0-9+\-]+', s[j:])
    if not m:
        return None, i
    return m.group(0), j + m.end()

def first_word(sub):
    r"""The first word of a \mathrm{...} subscript, or None. 'id,sym' gives 'id'."""
    m = re.match(r'\s*\\mathrm\{([A-Za-z]+)(?=[,}])', sub)
    return m.group(1) if m else None

def unbrace(text, letter):
    r"""\tilde{\Pi} to \tilde\Pi, so the three spellings meet one rule."""
    return re.sub(r'\\(tilde|vec)\s*\{\\%s\}' % letter,
                  lambda m: '\\' + m.group(1) + '\\' + letter, text)

def convert(text, letter, kind, glyph, accents, optional=False, emit=None):
    r"""optional: a site with no accent is a site too. emit: the accent written in
    place of the one matched, '' for none. Step 4 is the only caller that sets either."""
    alt = '|'.join(accents)
    pat = re.compile((r'(?:\\(%s)\s*)?\\%s(?![A-Za-z])' if (optional or emit is not None)
                      else r'\\(%s)\s*\\%s(?![A-Za-z])') % (alt, letter))
    out, i = [], 0
    while True:
        m = pat.search(text, i)
        if not m:
            out.append(text[i:])
            return ''.join(out)
        out.append(text[i:m.start()])
        accent = emit if emit is not None else ('\\' + m.group(1) if m.group(1) else '')
        j, sub = m.end(), None
        if j < len(text) and text[j] == '_':
            sub, j = read_sub(text, j)
            if sub is None:
                out.append(m.group(0))
                i = m.end()
                continue
        if sub is None:
            out.append('%s\\%s_{\\mathrm{%s}}' % (accent, glyph, kind))
        elif first_word(sub) in ('id', 'nil'):
            out.append('%s\\%s_{%s}' % (accent, glyph, sub))       # idempotent run
        else:
            w = re.match(r'\s*\\mathrm\{([A-Za-z]+)(?=[,}^])', sub)
            if w:
                tail = sub[w.end():]
                if tail.startswith('}'):
                    tail = tail[1:]
                out.append('%s\\%s_{\\mathrm{%s,%s}%s' % (accent, glyph, kind, w.group(1), tail) + '}')
            else:
                out.append('%s\\%s_{\\mathrm{%s},%s}' % (accent, glyph, kind, sub))
        i = j

for root in ('articles_physics', 'articles_maths'):
    for path in pathlib.Path(root).glob('*.md'):
        text = path.read_text()
        new = text
        for letter, glyph, kind, accents in SITES:
            for a in accents:

            new = convert(new, letter, kind, glyph, accents)
        if new != text:

14. What the First Run Changed Here

Four corrections, each with its evidence, so that a second run does not rediscover them.
